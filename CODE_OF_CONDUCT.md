# Code of Conduct

We want this to be a welcoming project for designers and engineers of every background and level.

**Expected:** be kind and specific; critique work, not people; assume good faith; credit others' ideas;
remember many contributors write in a second language.

**Not acceptable:** harassment, insults, discriminatory language or imagery, personal attacks,
publishing others' private information, sustained disruption.

**Enforcement:** maintainers may edit or remove contributions and temporarily or permanently ban
contributors who violate this code. Report issues privately to the maintainers via the contact listed
on the repository profile. Reports are handled confidentially.

Inspired by the Contributor Covenant (https://www.contributor-covenant.org).
