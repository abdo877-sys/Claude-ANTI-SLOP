# Workflow — creative agency / studio website

An agency sells its taste. The site itself is the first case study, so it may
be bolder than other workflows — but it must still be fast, accessible and
easy to contact.

## 1. Evidence
Services, sectors, 4–8 real case studies with assets and outcomes, team size
and culture, location, the client they want more of, the tone they use with clients.

## 2. Direction
Allowed to be Experimental, Cinematic, Editorial, Art-direction-driven or
Neo-brutalist — **if** the evidence supports it (their work and clients look
like that). A studio doing banking brand work shouldn't look like a rave flyer.
Define one bold idea (the signature move) and keep everything else disciplined.

## 3. Structure
- Home: positioning in one specific sentence, then work. Showreel only if it exists.
- Work index: filterable by sector/service if >8 projects; variable layouts.
- Case study: challenge → idea → craft (process artifacts) → outcome → credits.
- Studio/about: people, values shown through work, not adjectives. Open roles if any.
- Contact: project inquiry form with budget/timeline fields that actually submit, plus email.

## 4. Experimental safely
- Custom cursors, WebGL, scroll narratives: progressive enhancement only —
  the page must work and read without them, with reduced motion, and on mobile.
- Load heavy effects after LCP and only on capable devices.
- Navigation remains conventional enough to find "Work" and "Contact" in 3 seconds.

## Quality checks
- [ ] The bold idea is traceable to the studio's evidence (brief documents why)
- [ ] Works without JS effects; reduced-motion version is complete
- [ ] Mobile performance acceptable (measure LCP/INP if possible)
- [ ] Inquiry form submits, validates, confirms
- [ ] No claims of awards unless the user provided them
