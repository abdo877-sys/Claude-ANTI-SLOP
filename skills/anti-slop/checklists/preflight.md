# Preflight — before writing frontend code

Answer each in the brief (or in your reasoning for small tasks). A "no" blocks coding.

- [ ] I can state in one sentence who this is for and what they do here.
- [ ] I know the core object of the product and it will be visible on screen.
- [ ] I know the one primary action of this page/screen.
- [ ] I've read the existing stack, styling approach and 2–3 existing components.
- [ ] I know which locales/scripts and whether RTL is needed.
- [ ] A direction family is chosen with ≥2 pieces of evidence written down.
- [ ] I've written the refusals (what this design won't do).
- [ ] The default-look check passes (≤2 axes match).
- [ ] Tokens exist (or will be created first) — no literals in components.
- [ ] I know which content is real and which is placeholder the user must replace.
